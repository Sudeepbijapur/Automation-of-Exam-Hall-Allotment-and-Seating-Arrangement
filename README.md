# 🏫 Automation of Exam Hall Allotment and Seating Arrangement

An automated web-based system designed to simplify and manage examination hall allotment and student seating arrangements efficiently. This project reduces manual effort, minimizes errors, and provides a structured seating allocation process for educational institutions.

## 📌 Project Overview

Managing examination seating arrangements manually is a time-consuming and error-prone process. This project automates the allocation of exam halls and seating positions for students based on predefined criteria, ensuring a fair and organized examination environment.

The system helps administrators generate seating arrangements quickly while allowing students to easily access their allotted examination hall and seat information.

## 🚀 Features

* 🧑‍🎓 Student Exam Hall Allotment
* 🪑 Automatic Seating Arrangement Generation
* 🏫 Exam Hall Management

## ⚙️ Installation

### Clone the Repository


```bash
cd Automation-of-Exam-Hall-Allotment-and-Seating-Arrangement
```

### Run the Project

Open the `index.html` file in any web browser.

## ▶️ How It Works

1. Enter student and examination details.
2. Add available examination halls and seating capacity.
3. Generate seating arrangements automatically.
4. View allotted exam hall and seat details.
5. Manage and update seating information whenever required.
