# **App Name**: Exam Seating Sage

## Core Features:

- USN Search: Student USN Search: Allows students to enter their USN to find their seat details.
- Seat Details Display: Display Seat Details: Shows bench number, class, and location if within 10 minutes of the exam.
- Admin Authentication: Admin Login: Secure login for administrators to manage exam data.
- Add Class: Class Management: Admins can add classes with bench counts and locations.
- Add/Edit Batch: Batch Management: Admins can add and edit batches of students.
- Add Exam: Exam Scheduling: Admins can schedule exams, assign classes and batches, and publish them.
- Seat Allocation: Intelligent Seat Allocation: A tool ensures students from the same department are not seated together and avoids mixing CS and IS students.

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5) to convey a sense of trust and organization.
- Background color: Very light lavender (#F0F2FA) for a clean, uncluttered backdrop.
- Accent color: Amber (#FFC107) to highlight important actions and information.
- Body font: 'Inter' (sans-serif) for a modern and readable interface. Headline Font: 'Space Grotesk' (sans-serif) for clear headlines.
- Clean, centered layout for the student search page with a prominent search bar. Structured tables for admin data.
- Use simple, clear icons to represent different functions in the admin panel, enhancing usability.
